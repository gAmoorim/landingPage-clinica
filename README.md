# 🏥 Landing Page — Clínica Dr. Marcelo

> Landing page profissional para clínica de estética facial, desenvolvida em **React** com **Tailwind CSS**. Paleta teal/mint, design responsivo, integração direta com WhatsApp e animações suaves via Framer Motion.

---

## 🛠️ Tecnologias

| Tecnologia | Uso |
|---|---|
| [React](https://react.dev/) | Framework principal |
| [Tailwind CSS](https://tailwindcss.com/) | Estilização utilitária |
| [Framer Motion](https://www.framer.com/motion/) | Animações de entrada |
| [Lucide React](https://lucide.dev/) | Ícones |

---

## 🚀 Como usar

### Pré-requisitos

- Node.js 18+
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/landing-clinica-marcelo.git

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```
